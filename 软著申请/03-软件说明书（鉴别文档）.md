# 1 引言

## 1.1 编写目的

本文档是《启序待办管理软件 V2.0》的软件说明书，系统说明软件的用途、运行环境、总体设计、功能模块、数据结构、关键算法、界面设计以及隐私安全策略，作为软件的技术与使用文档，供软件著作权登记、软件交付及用户使用参考。

## 1.2 软件背景

注意力管理挑战人群（含注意缺陷多动障碍人群）在日常事务管理中常面临三个困难：念头多而散，来不及记录；任务大而难，不知从何下手；执行中易分心，难以持续专注。启序待办管理软件以「丢 — 捋 — 做」为核心工作流，提供低阻力的记录工具、以词为单元的整理工具和极简的执行工具，帮助用户一次只做好一件事。

软件早期版本曾用名「Start」，自 V2.0 起正式更名为「启序」，系同一作品的延续版本。

## 1.3 术语与缩略语

| 术语 | 含义 |
|---|---|
| 念头 | 用户快速记录、尚未分类的想法或事项 |
| 捋一捋 | 对记录内容按词/句拆分、分拣归类的整理过程 |
| 随手做 | 没有指定时间、可随时完成的任务 |
| 日程 | 指定了日期与时刻、可设置提醒的任务 |
| 今日焦点 | 用户从全部事务中选出的当前唯一重点任务 |
| 小步骤 | 大任务拆解后的顺序执行单元 |
| 离线语音 | 调用设备自带语音引擎、优先离线运行的语音识别方式 |
| WebDAV | 一种基于 HTTP 的文件管理协议，用于用户自备的云存储 |
| AGPL | GNU Affero 通用公共许可证，软件采用的开源许可证之一 |

# 2 软件概述

## 2.1 软件用途

启序是一款运行于 Android 平台的本地待办事项管理软件，提供「记录 — 整理 — 执行 — 回顾」全流程支持：

- **记录**：文字速记、语音速记，想到即记，不打断当前事务；
- **整理**：按词拆分整句、批量分拣为念头/随手做/日程，支持多选与拖拽；
- **执行**：时间轴日程、今日焦点、小步骤拆解、极简专注计时；
- **回顾**：完成统计、全局搜索与数据管理。

## 2.2 主要特点

1. **本地优先**：全部用户数据仅存储于设备本地，核心功能无需联网；
2. **低阻力措辞**：界面文案采用鼓励性表达，无责备式提示；
3. **以词为单元整理**：内置中文分词能力，整句一键拆成词单元；
4. **全局一致交互**：长按拖起、底部释放的删除方式全局统一，提供 6 秒撤销窗口；
5. **极简专注界面**：专注过程中仅显示空心圆环与倒计时数字；
6. **能力可选**：在线语音、AI 助手、云备份均默认关闭，用户自愿开启，不开启不联网；
7. **全面屏适配**：界面延伸至状态栏与手势条之后，跟随系统深色模式。

## 2.3 软件组成

软件由 Dart 业务代码（界面、状态、数据、服务）与 Kotlin 原生通道代码（语音识别、本地通知、日历、闹钟、震动、开机自启动）两部分组成，共 29 个源文件、10360 行源程序。

# 3 运行环境与安装

## 3.1 硬件环境

- Android 智能手机或平板电脑，支持 ARMv7 / ARM64 架构；
- 建议运行内存 2GB 及以上，可用存储 200MB 及以上；
- 使用语音功能需设备配备麦克风。

## 3.2 软件环境

- 操作系统：Android 10.0（API 29）及以上版本；
- 离线语音依赖设备系统提供的语音识别引擎及离线语音包（主流国产系统均内置厂商自研离线引擎）；
- 核心功能无需网络；检查更新需访问互联网；在线语音、AI 助手、WebDAV 云备份为可选联网功能。

## 3.3 安装与卸载

- 将安装包（APK）复制到手机后点击安装，首次启动需阅读并同意用户协议与隐私政策；
- 首次使用语音时系统弹窗申请麦克风权限，到点提醒功能申请通知权限，写入日历申请日历权限，用户可逐项授予或拒绝；
- 在系统「应用管理」中卸载即彻底删除全部数据，卸载前可在设置中导出 JSON 备份。

# 4 总体设计

## 4.1 设计理念

软件遵循「软件服务于人」的设计原则，追求简洁、一致与以人为本：

- **丢**：任何念头先收下，记录时不强制分类；
- **捋**：稍后通过分词与分拣把零散内容理顺；
- **做**：一次只选一个焦点，大事拆成小步骤，用极简计时器执行。

## 4.2 体系结构

软件采用分层结构：

```
┌─────────────────────────────────────────────┐
│  界面层（pages/widgets）                      │
│  首页 · 念头 · 捋一捋 · 动手吧 · 专注 · 统计 · 设置 │
├─────────────────────────────────────────────┤
│  服务层（services / ai）                     │
│  意图解析 · WebDAV 备份 · 更新检查             │
├─────────────────────────────────────────────┤
│  数据层（data）                              │
│  条目模型 · 本地存储 · JSON 导入导出          │
├─────────────────────────────────────────────┤
│  原生通道（channels + Kotlin）               │
│  语音识别 · 通知 · 日历 · 闹钟 · 震动 · 自启动 │
└─────────────────────────────────────────────┘
```

界面层通过统一的视觉设计令牌（颜色、间距、圆角、字号）保证风格一致；数据层以单一内存仓库配合持久化存储，任何设置变更即时刷新界面；原生通道通过方法通道与事件流和界面层通信。

## 4.3 导航结构

底部导航固定为五个槽位：念头、捋一捋、功能键（动手吧）、专注、统计。导航采用页面内嵌套导航器，底栏常驻；系统返回键与页内返回均回到首页并重置高亮。首页从上至下依次为：大时钟、日程时间轴、随手做、今日焦点。

## 4.4 功能模块划分

| 模块 | 主要职责 |
|---|---|
| 念头模块 | 快速记录想法，支持多行一次拆分多条 |
| 捋一捋模块 | 中文分词、按类分拣、多选批量删除 |
| 动手吧模块 | 文字与语音速记，拆分后进入整理 |
| 日程模块 | 时间轴、提醒、写日历、系统闹钟、拖拽设焦点 |
| 焦点与步骤模块 | 单一焦点任务、小步骤顺序执行 |
| 专注模块 | 圆环倒计时、可选滴答声、完成记录 |
| 统计模块 | 完成情况统计与可视化 |
| 搜索模块 | 全局检索与统一删除入口 |
| 扩展模块 | 在线语音开关、AI 助手配置、WebDAV 云备份 |
| 设置模块 | 外观、触感音效、后台保活、数据管理、协议文档 |

# 5 功能模块设计与操作说明

## 5.1 念头

用户在念头页底部输入条输入内容，回车可换行连续记录多条，保存时按行自动拆开，句末标点（。！？；…）同样作为分条边界。念头以卡片形式排列，支持编辑与拖拽删除。

【截图位置：念头页，底部输入条与若干念头卡片】

## 5.2 捋一捋

「捋一捋」对一段文本执行中文词元拆分，自动识别纯词、完整句子与词句混合输入并剥离标点，每个词生成一个可点选的标签芯片。用户可单击选中/取消芯片，选定内容批量归入随手做、日程或念头；顶部按钮进入多选态后可长按整组拖入底部删除区，一次删除、一次撤销。

【截图位置：捋一捋拆词结果页】

## 5.3 动手吧（速记）

底栏中央红色圆钮为「动手吧」：

- **短按**：打开文字速记页。先写下来不必分类，点「倒进来」后按行与句末标点拆成多件并进入捋一捋；
- **长按**：打开语音面板（见 5.10）。

【截图位置：动手吧文字速记页】

## 5.4 日程

日程在首页以时间轴呈现：左侧为时刻与轴线节点，未到期显示空心圆、已完成显示实心番茄红圆、过期显示灰圆，并有「现在」红线指示当前时刻；日历事件以小方点与任务圆圈区分。

日程编辑器含三个开关：

1. **提醒**（默认开启）：到点由软件弹出悬浮本地通知；
2. **写入日历**：将事项写入手机系统日历，已写入的显示「已在日历」并支持直达系统日历；
3. **系统闹钟**：跳转系统时钟，使用厂商闹钟响铃。

日程支持长按 0.12 秒起拖，拖到「今日焦点」区域时该区域高亮，松手即设为焦点；支持按行批量写入与批量删除。

【截图位置：首页日程时间轴，含「现在」红线】
【截图位置：日程编辑器的三个开关】

## 5.5 随手做与今日焦点

没有指定时间的任务仅出现在「随手做」区；设为焦点的任务仅显示在首页上方焦点卡，从下方列表隐藏以避免重复。焦点卡右侧依次为完成、换一件、编辑三个操作；点主胶囊「只做它」进入小步骤页，体现「事大先拆小」。

【截图位置：首页今日焦点卡】

## 5.6 小步骤

焦点任务进入小步骤页后可继续逐条添加步骤；标题不参与拆分，仅用户输入内容拆分；步骤输入条的拆词按钮常驻，输入框为空时点击自动聚焦输入框，有内容时执行拆词。步骤按顺序执行，完成后任务标记完成。

【截图位置：小步骤页】

## 5.7 专注

底栏「专注」为专注功能唯一入口。开始后界面仅显示空心圆环与倒计时数字，无任何状态或提示文本；可选滴答声与结束提示音，结束后记录一次完成。

【截图位置：专注计时进行中界面（仅圆环与数字）】

## 5.8 统计

统计页汇总任务完成数量与专注次数等数据，以图表形式呈现。

【截图位置：统计页】

## 5.9 搜索与全局删除

搜索页按关键词检索全部条目，结果行支持编辑、完成与拖拽删除。全局删除交互统一：长按任意卡片 0.12 秒拖起，原卡片半透明、浮影为整张卡片（多选时带数量角标），底部出现番茄红全屏释放区，拖入即删除；删除后浮出白卡红描边撤销条，6 秒内可撤销，撤销条在拖拽释放区完全收起后才出现，避免界面元素重叠；带输入条的页面中撤销条自动上浮避让。

【截图位置：拖起卡片时底部红色删除区与浮影】

## 5.10 语音速记

长按「动手吧」弹出语音面板：

1. 默认调用设备自带语音识别引擎并设置离线优先标志，枚举本机所有可用引擎（含厂商自研离线引擎），不依赖特定互联网服务；
2. 面板显示脉动麦克风、实时转写文字与「离线/在线」状态；
3. 说完一句自动续听，安静超时自动重开，直到用户手动结束；
4. 点「说完了」将全文送入动手吧文字页复核；点「取消」丢弃；
5. 用户在设置开启 AI 助手后，面板出现「AI 整理」，可直接将一段话结构化入库（见 5.11）。

【截图位置：语音面板识别中】

## 5.11 AI 助手（可选，默认关闭）

AI 助手在设置中手动启用，支持选择预设服务或填写任意兼容 OpenAI 接口协议的服务地址、模型名与密钥，并提供「测试连接」自检。

用户在语音面板点「AI 整理」后，软件将当时那段话发送至用户自配的服务，由大模型解析为动作数组：含明确时间的归为「日程」并换算绝对时间、自动开启提醒；灵感备忘归为「念头」；其余归为「随手做」；无关寒暄忽略。解析结果整批落库，并提供一次整批撤销。除该次请求外软件不发送任何数据。

【截图位置：设置中的 AI 助手配置页】

## 5.12 云备份（可选，默认关闭）

云备份基于 WebDAV 协议，兼容坚果云、群晖、Nextcloud 等服务。用户填写服务器地址、账号与密码后可：测试连接、立即备份（生成带时间戳的 JSON 文件上传至用户自备服务器）、从云端恢复最新一份（恢复前二次确认，恢复后 6 秒内可撤销）。不开启、不点击按钮不产生任何网络访问。

【截图位置：云备份配置与操作页】

## 5.13 设置

设置页分组包括：

- **外观**：深色模式（跟随系统/开/关）、字号（小/中/大）；
- **触感与音效**：按压触感、专注滴答声、通知方式、音量；
- **后台保活**：常驻通知防误杀、到点悬浮提醒、开机自启动；
- **数据**：导出 JSON、导入 JSON（导入前自动快照）、清空全部条目；
- **扩展**：在线语音识别开关、AI 助手、云备份；
- **关于**：检查更新、使用说明、用户协议、隐私政策、开源协议、项目源码、联系作者。

# 6 数据结构与存储设计

## 6.1 条目模型

每条记录为一个条目对象，核心字段如下：

| 字段 | 类型 | 含义 |
|---|---|---|
| id | 整数 | 条目唯一标识 |
| kind | 整数 | 类型：随手做/日程/念头/小步骤等 |
| title | 字符串 | 标题内容 |
| dueTime | 整数 | 日程时间（毫秒时间戳），无时间为 0 |
| alarm | 布尔 | 是否到点提醒 |
| rank | 整数 | 手动排序权重 |
| done | 布尔 | 是否完成 |
| created | 整数 | 创建时间（毫秒时间戳） |
| parentId | 整数 | 小步骤所属任务的标识 |
| calendarId/eventId | 字符串 | 写入系统日历后的回执标识 |

## 6.2 存储方式

- 条目数据持久化于设备本地应用私有存储；设置项以键值对保存于本地偏好存储；
- 数据不写入公共目录、不上传服务器；
- 导出功能将全部条目序列化为 JSON 文件，导入时校验格式后整体恢复，恢复前自动保存快照；
- 备份文件名形如 `qixu-backup-yyyymmddHHMMSS.json`。

## 6.3 通知调度

日程提醒与常驻通知由原生层负责：创建/修改/删除日程时同步登记或取消系统定时任务；设备重启后由开机广播接收器重新登记全部未到期提醒，防止重启丢失。

# 7 关键算法与技术实现

## 7.1 中文词元拆分

捋一捋与小步骤共用同一拆分规则：以中文词元为边界进行拆分，可自动处理纯词、完整句子和词句混合输入；标点符号被剥离；文字速记额外以换行与句末标点（。！？；…）作为分条边界。该规则在念头、动手吧、小步骤三处保持一致。

## 7.2 全局拖拽删除

基于长按拖拽组件实现，拖拽浮影置于根覆盖层以保证位于所有页面元素之上；通过全局状态总线通知底部删除区显隐并携带待删除集合；删除区采用左右通栏、延伸至系统手势条之后的全屏释放设计。多选时所有选中卡片在拖拽过程中统一半透明，浮影角标显示条数。

## 7.3 撤销避让

撤销条以全局浮层实现，内部保存删除前快照，6 秒倒计时后失效。为避免撤销条与拖拽删除区同屏重叠，撤销条在拖拽状态总线变为空闲后再弹出；在含输入条的页面，撤销条上浮至输入条上方。

## 7.4 离线语音识别

原生层通过系统语音识别接口实现：枚举设备已安装的全部语音引擎（含厂商自研离线引擎），构造识别意图时指定中文（zh-CN）、自由句式、返回部分结果，并在设置未开启在线识别时附加离线优先标志；识别事件通过事件流向界面层推送就绪、中间结果、最终结果、音量、错误等类型。错误码中表示超时、无语音、引擎忙的情形按正常停顿处理并自动续听。

## 7.5 AI 意图解析

AI 解析采用结构化提示词约束模型仅输出 JSON 动作数组，每个动作包含动作类型（日程/随手做/念头/无）、精简标题与绝对时间；软件对返回结果做容错提取（正则提取数组、逐字段校验、时间解析失败降级为无时间任务），落库前先导出快照用于整批撤销。

## 7.6 本地通知与保活

到点提醒使用系统本地通知通道，不经过任何服务器；常驻通知为低优先级静默通知，配合开机自启动降低国产系统后台回收影响；提醒时间由软件根据条目时间统一调度。

## 7.7 界面设计令牌

颜色、描边、间距、圆角、字号均由统一的设计令牌管理，主强调色统一为番茄红（#FF6347），深色模式提供整套令牌；状态栏与导航栏透明并由系统图标样式跟随日夜切换。

# 8 用户界面设计

## 8.1 设计原则

- 全局操作元素优先使用图标，不使用文字按钮堆叠；
- 内置图标采用统一墨色的极简单色风格；
- 底部导航五个槽位等距分布，按钮不拥挤、不出屏；
- 同一操作在所有页面使用同一图标（如编辑统一为铅笔图标）；
- 数字排版对齐，避免错位。
